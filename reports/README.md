# Reports

تقارير JSON/CSV/Markdown الصغيرة الناتجة من القياس. لا تُرفع أوزان النماذج أو بيانات غير عامة.

## Evidence classes

- `smoke/`: نتائج تشغيل تشخيصية على بيانات الدورة الصغيرة وموسومة `MEASURED_SMOKE`. هذه الملفات تثبت أن المسار يعمل وتوثّق ما حدث فعليًا، لكنها ليست دليلًا مستقلًا على اجتياز بوابات R1–R7 الرسمية.
- `T9_MANUAL_REVIEW.md` و`t9_manual_error_review.csv`: أدلة تحليل الأخطاء والمراجعة اليدوية الحالية.
- `t10_local_cpu_http_benchmark.json`: قياس real-HTTP محلي على CPU؛ بيئته موثقة داخل الملف والتقارير الرئيسية.

يجب تفسير كل رقم بحسب مصدر البيانات وبيئة القياس، وعدم تحويل نتائج smoke إلى ادعاء تقييم رسمي مجمد.
